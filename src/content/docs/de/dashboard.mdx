RIM verfügt über ein webbasiertes Dashboard, das verschiedene Aufgaben im Bereich der Geräte- und Kontoverwaltung erleichtert. Sie können Ihre vorhandenen unbeaufsichtigten Computer verwalten, vorkonfigurierte Installationsprogramme für Zielcomputer erstellen und vieles mehr.  
Es ist zu beachten, dass der Funktionsumfang des Dashboards weitgehend davon abhängt, welche Abonnementstufe Ihr Konto hat. Beispielsweise können Unternehmensnutzer Rechner Zielgruppen zuweisen sowie „Silent“-Installationsprogramme erstellen. Andererseits kann jeder (einschließlich Privatanwender) benutzerdefinierte Installationsprogramme für seine unbeaufsichtigten Rechner erstellen.

### Das Dashboard finden

Wenn Sie ein Controller sind, gelangen Sie am einfachsten über die RIM-Hauptoberfläche zum Dashboard. Durch Klicken auf die Schaltfläche „RIM-Dashboard“ wird das Dashboard automatisch in Ihrem Standardbrowser geöffnet, wobei die Anmeldung bereits erfolgt ist.  
Wenn Sie ein Netzwerkadministrator sind, auf dessen Rechner RIM nicht installiert ist, können Sie sich einfach auf der RIM-Website in Ihr Konto einloggen – daraufhin wird Ihr Dashboard angezeigt.

### Mitglieder der Organisation verwalten (Unternehmen)

Wenn Sie auf dem RIM-Dashboard die Schaltfläche „Organisation“ anklicken, wird ein Menü mit Optionen zur Verwaltung der Organisation und ihrer Mitglieder angezeigt. Auf der Seite „Mitglieder“ werden alle Mitglieder Ihrer Organisation aufgelistet. Bei allen Mitgliedern können Rolle, Abteilung und Name geändert werden, und jedes Mitglied – mit Ausnahme des Organisationsinhabers – kann deaktiviert oder aus der Organisation entfernt werden. Beachten Sie, dass durch die Deaktivierung eines Mitglieds dessen Konto unbrauchbar wird, der Datensatz jedoch erhalten bleibt.

Das Hinzufügen von Mitgliedern erfolgt ganz einfach durch Eingabe der E-Mail-Adresse, Auswahl der Rolle (Benutzer oder Administrator), optionale Eingabe des Namens und Auswahl der Abteilung, sofern eine angelegt wurde.
Wenn Sie mehrere Mitglieder hinzufügen möchten, können Sie das Bearbeitungsfeld „Mitglieder“ für eine Massenhinzufügung nutzen. Dieses Eingabefeld akzeptiert mehrere Textzeilen, sodass Sie die Informationen jedes Mitglieds in einer separaten Zeile eingeben können. In jeder Zeile können Sie entweder eine einzelne E-Mail-Adresse oder eine E-Mail-Adresse und einen Namen im folgenden Format eingeben:  
*email@example.com John Doe*

Wenn Sie fertig sind, klicken Sie auf die Schaltfläche „Hinzufügen“. 

#### Abteilungen

Mit Abteilungen können Sie Mitglieder entsprechend den verschiedenen Gruppen Ihrer Organisation organisieren.

Um eine Abteilung hinzuzufügen, geben Sie deren Namen in das Eingabefeld „Name“ unter der Überschrift „Abteilung erstellen“ ein.

#### Export von Mitgliederdaten

Die Mitgliederliste Ihrer Organisation kann als CSV-Datei exportiert werden. So laden Sie den Export herunter:
1. Wählen Sie das Feldtrennzeichen aus, das die Spalten der Datei trennen soll. Zu den verfügbaren Optionen gehören:
    * Komma
    * Semikolon
    * Tabulator
1. Klicken Sie auf die Schaltfläche „Herunterladen“.

#### Einschränkungen

Je nach Art Ihrer Organisation gibt es möglicherweise bestimmte Funktionen, auf die Ihre Mitarbeiter keinen Zugriff haben sollen. Daher können Organisationsadministratoren auswählen, auf welche Funktionen sie den Controllern Zugriff gewähren möchten. Auf dem Bildschirm „Einschränkungen“, der über das Menü „Organisation“ aufgerufen wird, können Sie diese Berechtigungen konfigurieren.

Zu den Berechtigungen, die aktiviert oder deaktiviert werden können, gehören:
* Dem Controller erlauben, die Sitzung umzuschalten
    * Wenn diese Option deaktiviert ist, verschwindet die Option „Sitzung umschalten“ aus dem Sitzungsmenü, und die Tastenkombination funktioniert nicht.
* Dem Controller erlauben, ein Sprachgespräch zu starten
    * Ist diese Option deaktiviert, verschwindet das Kontrollkästchen „Sprachgespräch starten“ aus dem Bildschirm „Fernhilfe bereitstellen“, ebenso wie die entsprechende Menüoption im Sitzungsmenü.
* Dem Controller erlauben, unbeaufsichtigten Zugriff anzufordern
    * Ist diese Option deaktiviert, verschwindet die Option zur Anforderung unbeaufsichtigten Zugriffs aus dem Sitzungsmenü.
* Übertragung von Text und Dateien zwischen Computern über die Zwischenablage zulassen
    * Wenn diese Option deaktiviert ist, ignoriert RIM jegliche Aktivitäten in der Zwischenablage.
* Dem Controller erlauben, den Zielcomputer zu sperren
    * Wenn diese Option deaktiviert ist, verschwindet die Option zum Sperren des Zielcomputers aus dem Sitzungsmenü.
* Dem Controller erlauben, die Sitzung aufzuzeichnen
    * Diese Option ist standardmäßig deaktiviert, wodurch die Sitzungsaufzeichnung zu einer Funktion wird, die ausschließlich von Unternehmensorganisationen und/oder Pro-Kunden mit dem Enterprise-Add-on aktiviert werden kann.
    * Wenn diese Option deaktiviert ist, verschwindet die Option zur Aufzeichnung der Sitzung aus dem Sitzungsmenü.
    * Diese Einschränkung deaktiviert zusätzlich die clientseitige Einstellung „auto_start“ in der Datei „config.toml“
* Text-Chat während der Sitzung zulassen
    * Diese Option ist standardmäßig deaktiviert, sodass der Sitzungs-Chat eine Funktion ist, die ausschließlich von Unternehmensorganisationen und/oder Pro-Kunden mit dem Enterprise-Add-on aktivieren können.
    * Ist diese Option deaktiviert, verschwindet die Option zum Öffnen des Chats aus dem Sitzungsmenü.
* Dem Controller das Durchsuchen und Übertragen von Dateien auf dem Zielrechner über den Dateibrowser erlauben
    * Ist diese Option deaktiviert, verschwindet die Option zum Durchsuchen von Dateien auf dem Zielrechner aus dem Sitzungsmenü.
* Erlauben, dass neue Zielrechner zur Standardgruppe hinzugefügt werden, auf die jeder Controller in der Organisation zugreifen kann
    * Wenn diese Option deaktiviert ist, können Rechner nur zu bestimmten Zielgruppen hinzugefügt werden.
    * Das Deaktivieren dieser Option entfernt keine Rechner, die vor der Änderung zur Standardgruppe hinzugefügt wurden.

Sobald Sie die Berechtigungen nach Ihren Wünschen konfiguriert haben, klicken Sie auf die Schaltfläche „Aktualisieren“. Die meisten Änderungen werden sofort in allen Sitzungen wirksam, die zum Zeitpunkt der Änderung der Berechtigungen aktiv sind. Insbesondere:

* Eine gespiegelte Sitzung wird sofort wiederhergestellt.
* Ein aktives Sprachgespräch wird beendet.
* Eine ausstehende Anfrage für unbeaufsichtigten Zugriff wird abgebrochen.
* Zwischenablagevorgänge, einschließlich laufender Dateiübertragungen, werden beendet.
* Eine laufende Sitzungsaufzeichnung wird sofort beendet. RIM verwirft die Aufzeichnung jedoch nicht.
* Ein laufender Text-Chat wird beendet.
* Der Dateibrowser verschwindet, und alle laufenden Dateiübertragungen werden abgebrochen.

### Ziele verwalten

Wenn Sie auf den Link „Ziele konfigurieren“ klicken, gelangen Sie zu einer Seite, auf der Sie alle Rechner verwalten können, die Sie für den unbeaufsichtigten Zugriff konfiguriert haben. Sie können auf einen beliebigen dieser Rechner klicken, um ihn zu verwalten. Dort haben Sie folgende Möglichkeiten:

* Das Ziel umbenennen
* Das Ziel in eine andere Gruppe verschieben (mehr zu Zielgruppen später)
* Eine Remote-Sitzung mit dem Ziel starten
* Das Ziel löschen

### Zielgruppen (für Pro-Konten und höher)

Nehmen wir beispielsweise an, Ihre Arbeitsgruppe ist auf mehrere verschiedene Standorte verteilt. Oder vielleicht möchten Sie Ihren Technikern für die routinemäßige Wartung Gruppen von Computern zuweisen. Mit Zielgruppen ist genau das möglich. Klicken Sie dazu einfach auf die Schaltfläche „Zielgruppe erstellen“, benennen Sie Ihre Gruppe und bestätigen Sie die Eingabe.  
Sie können so viele Zielgruppen anlegen, wie für Ihren Anwendungsfall erforderlich sind. 

#### Zugriffskontrolle (für Unternehmensorganisationen)

Wenn Ihre Organisation einem Support-Techniker eine bestimmte Gruppe von Rechnern zuweist, möchten Sie wahrscheinlich sicherstellen, dass dieser nur Zugriff auf genau diese Gruppe hat. Hier kommt die Einstellung zur Zugriffskontrolle für Zielgruppen ins Spiel.  
Wenn Sie auf eine Zielgruppe klicken, erhalten Sie Optionen zur Verwaltung der Rechner in der Gruppe sowie der Gruppe selbst. Im Abschnitt „Zugriffskontrolle“ können Sie dieser Gruppe auf Einzelkontobasis Zugriff gewähren. Geben Sie einfach die E-Mail-Adresse des Kontos ein, das Sie hinzufügen möchten, und klicken Sie dann auf die Schaltfläche „Zugriff gewähren“. Beachten Sie, dass dieses Konto außerhalb der Domain Ihrer Unternehmensorganisation liegen kann.  
Sobald dies erledigt ist, wird Ihnen eine Tabelle mit den Konten angezeigt, denen Zugriff auf diese Gruppe gewährt wurde. Unter jedem Konto befindet sich die Schaltfläche „Zugriff widerrufen“. Diese Schaltfläche erfordert keine weitere Bestätigung.  
Es ist zu beachten, dass allen Organisationsadministratoren automatisch Zugriff gewährt wird, um alle Gruppen zu verwalten, die unter der Organisation angelegt wurden. Zudem werden alle E-Mail-Adressen unter den Domains Ihrer Organisation standardmäßig zu Ihrer Organisation in RIM hinzugefügt. Sollten Sie eine detailliertere Kontrolle darüber benötigen, wer hinzugefügt wird, können Sie diese Funktion im Hauptmitgliederbereich Ihrer Organisation deaktivieren. Darüber hinaus können Sie im Mitgliederbereich E-Mail-Adressen in großen Mengen hinzufügen, indem Sie die Adressen durch Kommas, Leerzeichen oder Zeilenumbrüche voneinander trennen.

### Einrichten eines vorkonfigurierten RIM-Installationsprogramms (Pro oder höher)

Eine der einfachsten Möglichkeiten, einen Rechner für unbeaufsichtigte oder abfragegesteuerte Verbindungen einzurichten, ist die Erstellung eines benutzerdefinierten Installationsprogramms. Dies ist äußerst nützlich, wenn Sie Massenbereitstellungen konfigurieren, oder auch als einfachere Methode, um RIM auf dem Computer eines Endbenutzers in Betrieb zu nehmen, für den Sie regelmäßig Support leisten möchten.

Gehen Sie dazu wie folgt vor:
1. Klicken Sie im Zielverwaltungsbildschirm auf die Schaltfläche „Zielinstallationsprogramm erstellen“.
1. Sie werden zunächst gefragt, ob dieser Rechner für einen vollständig unbeaufsichtigten Zugriff oder für einen Zugriff mit Aufforderung konfiguriert werden soll, bei dem der Benutzer eine Aufforderung akzeptieren muss, um die Verbindung herzustellen.
1. Anschließend werden Sie nach einer Zielgruppenzuordnung gefragt. Beachten Sie, dass die Zielgruppenauswahl automatisch auf die von Ihnen gewählte Zielgruppe zurückgreift, wenn Sie die Installationskonfiguration über die Seite Ihrer Gruppe starten.
1. Sie werden gefragt, wie lange dieser Installer gültig sein soll. Die Gültigkeitsdauer kann zwischen 7 und 30 Tagen liegen oder – bei Enterprise-Tarifen – dauerhaft gültig sein, indem Sie das Ablaufdatum auf „nie“ setzen.
1. Anschließend haben Sie die Möglichkeit, einen Basisnamen zu vergeben. Jedem Rechner, der über dieses Installationspaket bereitgestellt wird, wird dieser Basisname zugewiesen.
1. Es wird Ihnen dann ein Kontrollkästchen angezeigt, mit dem Sie sich für eine E-Mail-Benachrichtigung anmelden können, wenn ein Benutzer RIM über diesen Installer installiert.
1. Wenn Sie Unternehmensadministrator sind, sehen Sie ein Kontrollkästchen, mit dem Sie das Installationsprogramm als MSI-Paket erstellen können. Diese Option ist nützlich für die Massenbereitstellung eines benutzerdefinierten Installationsprogramms auf einem Rechnercluster, der für die jeweilige Zielgruppe vorgesehen ist.
1. Sie werden aufgefordert, einen Namen für das Installationsprogramm und optional einige Anmerkungen anzugeben. Diese dienen der internen Dokumentation und erscheinen nicht im erstellten Installationsprogramm.
1. Klicken Sie auf „Installationsprogramm erstellen“. Sie erhalten einen Download-Link, den Sie entweder in die Zwischenablage kopieren und an Ihren Endbenutzer senden können. Alternativ können Sie das Installationsprogramm direkt herunterladen, um es bei Massenbereitstellungen zu verwenden. Sie können das Installationsprogramm auf diesem Bildschirm löschen, falls Sie es vorzeitig unbrauchbar machen möchten.

Nachdem Sie nun über Ihr Installationsprogramm verfügen, kann es auf zwei Arten ausgeführt werden. In beiden Fällen fragt das Installationsprogramm den Server ab, um die Gültigkeit des Installationsprogramms zu überprüfen. Ist das Installationsprogramm gültig, wird der Rechner nach Abschluss der Installation sowohl in Ihrem Konto als auch im RIM-Client zu Ihrer Rechnerliste hinzugefügt. Ein ungültiges Installationsprogramm wird nicht ausgeführt.

#### Normale Ausführung

Beim Ausführen des Installationsprogramms erhält der Benutzer eine Eingabeaufforderung mit den folgenden Informationen:
* Den Namen des Technikers sowie gegebenenfalls dessen Organisation
* Die Art der Verbindung, d. h., ob eine Eingabeaufforderung erforderlich ist oder nicht

Der Benutzer kann wählen, ob er die Installation mit „Ja“ oder „Nein“ bestätigen möchte. Bei einer Ablehnung wird die Installation abgebrochen. Nach Abschluss des Installationsvorgangs erhält der Benutzer eine Meldung, dass sein Rechner nun für den Fernzugriff eingerichtet ist.

#### Unbeaufsichtigte Installation (nur Enterprise-Installationsprogramme)

Eine unbeaufsichtigte Installation kann durch Ausführen der ausführbaren Installationsdatei mit dem Befehlszeilenparameter */S* gestartet werden. Dies ist nützlich, wenn RIM im Rahmen einer Massenbereitstellung installiert wird.

### Sitzungsverlauf

Über das RIM-Dashboard können Sie den gesamten Verlauf vergangener Sitzungen einsehen. Der Sitzungsverlauf enthält derzeit das Datum und die Uhrzeit jeder Sitzung, den Namen des Computers, mit dem Sie eine Verbindung hergestellt haben, sowie die Dauer der Sitzung. Sie können einer Sitzung außerdem über den Link „Kommentar hinzufügen“ in der Sitzungszeile Kommentare hinzufügen. Dies ist nützlich, um Notizen zum aktuellen Status eines Vorfalls sowohl für sich selbst als auch für die Administratoren der Organisation hinzuzufügen.

Ihr gesamter Sitzungsverlauf kann zur späteren Ansicht in eine Tabellenkalkulationsanwendung exportiert werden. Klicken Sie auf die Schaltfläche „Sitzungsverlauf als CSV herunterladen“ unterhalb der Tabelle mit dem Sitzungsverlauf, um eine Seite zur Anpassung des Datenexports aufzurufen. Auf dieser Seite können Sie den Zeitraum für den Export sowie das Trennzeichen für die Felder auswählen.

### Verwaltung Ihres Abonnements (Tarife „Personal“ und „Pro“)

Über das Dashboard können Sie die Details Ihres RIM-Abonnements einfach einsehen und verwalten. Wenn Sie auf den Link „Abonnement verwalten“ klicken, haben Sie folgende Möglichkeiten:
* Ihren Tarif upgraden
* Ihre Zahlungsmethode aktualisieren
* Wiederkehrende Zahlungen kündigen

#### Upgrade Ihres Tarifs

Sie können Ihr Abonnement ganz einfach upgraden. Wenn Sie einen Monatsplan nutzen, wird die verbleibende Gebühr anteilig vom neuen Betrag abgezogen, wobei für die folgenden Monate der volle neue Betrag berechnet wird. Wenn Sie auf „Abonnement upgraden“ klicken, wird eine Seite angezeigt, die fast identisch mit der ursprünglichen Planauswahlseite ist. Es gibt einige wichtige Unterschiede, die wir im Folgenden erläutern:
* Sie können Ihren Tarif nicht auf einen Tarif mit weniger Maschinen herabstufen. Sie können jedoch von einem Monats- auf einen Jahrestarif mit derselben Anzahl an Maschinen wie bei Ihrem aktuellen Tarif upgraden. Um eine Herabstufung vorzunehmen, müssten Sie Ihren Tarif kündigen, dessen Ablauf abwarten und anschließend einen neuen Tarif mit weniger Maschinen abschließen.
* Enterprise-Tarife, einschließlich des Enterprise-Add-ons, können nicht direkt über diese Seite erworben werden.

#### Kündigen wiederkehrender Zahlungen

Wenn Sie auf „Automatische Verlängerung kündigen“ klicken, werden Sie um eine Bestätigung gebeten. Danach läuft Ihr Abonnement am Ende der aktuellen Laufzeit aus.
