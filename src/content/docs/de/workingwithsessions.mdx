### Was Sie vor dem Start wissen sollten

Unmittelbar nach dem Herstellen der Verbindung geschehen einige Dinge.

<Windows>

* Das Fernsteuerungsfenster für die Sitzung wird angezeigt. Dieses Fenster lässt sich sowohl auf einem einzelnen Bildschirm als auch in einer Konfiguration mit mehreren Monitoren verschieben und in der Größe anpassen.
* Sie werden darüber informiert, ob auf dem Client-Rechner ein Bildschirmleseprogramm läuft oder nicht.
* Wenn auf dem Client ein Bildschirmleseprogramm läuft, bestätigt eine Toast-Benachrichtigung, die den Benutzer darüber informiert, dass die Remote-Sitzung begonnen hat, sofort, dass die System-Audioausgabe des Benutzers funktioniert.
* Auf einem Mac-Zielcomputer wird der Tastatur-Einrichtungsassistent angezeigt, wenn sich ein Controller zum ersten Mal mit ihm verbindet.
    * Dies gilt für die virtuelle Tastatur „Karabiner“, die auf Tastaturbefehle reagiert, die ihr von einem Controller gesendet werden.
    * Daher sollten Sie den Zielcomputer durch den Einrichtungsassistenten führen, da dieser während des Identifizierungsprozesses auf Tastendrücke von der Remote-Tastatur wartet und nicht auf die Tastatur des Macs selbst.
* Zu guter Letzt werden alle Tastatur- und Mauseingaben sofort an den Zielcomputer weitergeleitet. Um die Steuerung wieder auf Ihren Rechner zurückzuführen, führen Sie einen der folgenden Schritte aus:
    * Drücken Sie Windows+Umschalt+Rücktaste.
    * Klicken Sie mit der rechten Maustaste auf die Titelleiste des RIM-Fensters.
    * Klicken Sie mit der linken Maustaste auf das RIM-Symbol in der Mitte der Titelleiste.

</Windows>

<MacOS>

* Das Fernsteuerungsfenster für die Sitzung wird angezeigt. Dieses Fenster lässt sich sowohl auf einem einzelnen Bildschirm als auch in einer Konfiguration mit mehreren Monitoren verschieben und in der Größe anpassen.
* Sie werden über den Status des laufenden Bildschirmleseprogramms – oder dessen Fehlen – auf dem Client-Computer informiert.
* Wenn auf dem Client ein Bildschirmleseprogramm läuft, bestätigt eine Toast-Benachrichtigung, die den Benutzer darüber informiert, dass die Remote-Sitzung begonnen hat, sofort, dass die System-Audioausgabe des Benutzers funktioniert.
* Bei einem Mac-Zielcomputer wird der Tastatur-Einrichtungsassistent angezeigt, wenn sich ein Controller zum ersten Mal mit ihm verbindet.
    * Dies gilt für die virtuelle Tastatur „Karabiner“, die auf Tastaturbefehle reagiert, die ihr von einem Controller gesendet werden.
    * Daher sollten Sie den Zielcomputer durch den Einrichtungsassistenten führen, da dieser während des Identifizierungsprozesses auf Tastendrücke von der Remote-Tastatur wartet und nicht auf die Tastatur des Macs selbst.
* Zu guter Letzt werden alle Tastatur- und Mauseingaben sofort an den Zielcomputer weitergeleitet. Um die Steuerung wieder auf Ihren Rechner umzuleiten, führen Sie einen der folgenden Schritte aus:
    * Drücken Sie Option+Umschalt+Rücktaste.
    * Klicken Sie mit der rechten Maustaste auf die Titelleiste des RIM-Fensters.
    * Klicken Sie mit der linken Maustaste auf das RIM-Symbol in der Mitte der Titelleiste.

</MacOS>

### Fernsteuerungsbereich

<Windows>

Nun sind Sie bereit, alle erforderlichen Aufgaben auf der Client-Seite auszuführen. Sollten Sie wieder zur Steuerung Ihres eigenen Computers zurückwechseln müssen, rufen Sie das RIM-Menü auf und wählen Sie die Option „Sitzung minimieren“. Sie kehren zu Ihrem eigenen Rechner zurück, bis Sie wieder in das Sitzungsfenster wechseln oder erneut Windows+Umschalt+Rücktaste drücken. Wenn Sie wieder in das Sitzungsfenster wechseln, werden Tastatur- und Mauseingaben erneut an den Client-Computer weitergeleitet.

</Windows>

<MacOS>

Nun können Sie alle erforderlichen Aufgaben auf der Client-Seite ausführen. Sollten Sie wieder zur Steuerung Ihres eigenen Computers wechseln müssen, rufen Sie das RIM-Menü auf und wählen Sie die Option „Sitzung minimieren“. Sie werden zu Ihrem eigenen Rechner zurückgeleitet, bis Sie wieder in das Sitzungsfenster wechseln oder erneut Option+Umschalt+Backspace drücken. Wenn Sie wieder in das Sitzungsfenster wechseln, werden Tastatur- und Mauseingaben erneut an den Client-Computer weitergeleitet.

</MacOS>

Sobald Sie fertig sind, kann entweder der Controller oder der Zielcomputer das RIM-Menü aufrufen und die Option „Sitzung trennen“ wählen. Wenn die Sitzung beendet wird, erhält der Zielcomputer eine Toast-Benachrichtigung, die ihn darüber informiert.

## Das RIM-Menü

Wie bereits erwähnt, gelangen Sie durch den Aufruf des RIM-Menüs zurück zu Ihrem eigenen Rechner. Dieses Menü enthält eine Reihe von Optionen, darunter:  

<Windows>

* RIM auf dem Zielcomputer aktualisieren: Erzwingt eine Aktualisierung von RIM auf dem Zielcomputer
    * Diese Option wird angezeigt, wenn auf dem Zielcomputer eine ältere Version von RIM ausgeführt wird.
* RIM auf dem Zielrechner als Administrator neu installieren: Diese Option versucht, RIM auf einem Windows-Zielrechner als Administrator neu zu installieren, wobei der Zielbenutzer die Anfrage nach Administratorrechten selbst und/oder mit Hilfe der IT-Abteilung seines Unternehmens akzeptieren muss.
* Sitzung minimieren (**Windows+Umschalt+M**): Überträgt die Kontrolle wie oben beschrieben zurück auf Ihren Rechner
* Chat öffnen: Öffnet den Text-Chat für eine bestimmte Sitzung
    * Beachten Sie, dass diese Option zusätzlich im Sitzungsmenü auf der Zielseite erscheint.
* Datei an Ziel übertragen: Wird angezeigt, wenn sich eine Datei in der Zwischenablage befindet.
    * Diese alternative Methode zur Durchführung einer Dateiübertragung ist zwar immer verfügbar, wird jedoch nur für die Übertragung von Dateien auf Mac-Zielrechner benötigt.
* Dateien auf dem Zielrechner durchsuchen: Ermöglicht Dateiübertragungen, indem das Dateisystem des Zielcomputers in einem eigenen Fenster geöffnet wird.
    * Diese Methode der Dateiübertragung erfordert während Schlüsselwort-Sitzungen die Erlaubnis des Zielbenutzers.
    * Diese Option wird für einen Controller, der innerhalb einer Unternehmensorganisation arbeitet, nur angezeigt, wenn die Organisation diese Funktion aktiviert hat.
* Sitzung umschalten (**Windows+Umschalt+F**): Ermöglicht es Ihrem Client, Ihren Rechner fernzusteuern und dessen Audio zu hören. Als ursprünglicher Controller können Sie die Sitzung durch erneutes Auswählen dieser Option wieder zurückschalten.
* Sprachchat starten/beenden: Ermöglicht es Ihnen, den Sprachchat für Ihre Sitzung ein- oder auszuschalten.
    * Während einer unbeaufsichtigten Sitzung wird bei dieser Option ein Berechtigungsdialog angezeigt, auf den der Benutzer nur reagieren kann, wenn er anwesend ist. Bei abgefragten Sitzungen wird der Sprachchat jedoch weiterhin durch die Aktivierung durch den Controller initiiert.
* Sitzungsaufzeichnung starten: Startet die Aufzeichnung des Inhalts der aktiven Sitzung – mehr dazu später
    * Wenn die Sitzungsaufzeichnung aktiviert ist, wird diese Option durch Folgendes ersetzt:
        * Sitzungsaufzeichnung anhalten/fortsetzen (Umschaltfunktion)
        * Sitzungsaufzeichnung beenden: Beendet die Aufzeichnung und speichert sie
* Fernzugriff aktivieren: Diese Option wird angezeigt, wenn auf dem Remote-Computer kein Bildschirmleseprogramm ausgeführt wird. Dadurch wird die Sprachausgabe auf Ihrer Seite aktiviert, der Client muss sich jedoch keine Gedanken darüber machen, ob er die Sprachausgabe hört.
    * Wenn ein Bildschirmleseprogramm (einschließlich „Remote Accessibility“) läuft, wird diese Option zu einer Funktion zum erzwungenen Beenden des laufenden Bildschirmleseprogramms. Dies ist nützlich, wenn das Bildschirmleseprogramm des Zielcomputers nicht mehr reagiert und Sie es nicht mehr normal neu starten können.
* Audioausgabe des Zielcomputers stummschalten: Ermöglicht es Ihnen, die System-Audioausgabe des Remote-Computers stummzuschalten.
    * Beachten Sie, dass ein laufendes Sprachgespräch auch bei aktivierter Einstellung weiterhin besteht, sodass Sie mit der Person, mit der Sie verbunden sind, sprechen können, während deren Systemton für Sie nicht hörbar ist.
* Neustart und erneute Verbindung: Ermöglicht es Ihnen, den Computer neu zu starten und die Sitzung automatisch wiederherzustellen.
    * Beachten Sie, dass ein Mac-Zielcomputer RIM aufgrund von Plattformbeschränkungen, insbesondere FileVault, nicht vor der Anmeldung starten kann.
    * Daher stellt RIM die Verbindung wieder her, sobald sich der Benutzer anmeldet.
* „Strg+Alt+Entf“ senden: Sendet diese Tastenkombination an den Remote-Computer.
    * Eine entsprechende Funktion für diese Option ist für Mac-Zielrechner noch nicht implementiert.
* „Unbeaufsichtigten oder abgefragten Zugriff anfordern“: Ermöglicht es Ihnen, eine Anfrage für unbeaufsichtigten Zugriff auf den Client-Computer zu senden. Dies ist nützlich, wenn Sie als Systemadministrator routinemäßige Wartungsarbeiten durchführen müssen oder auch einfach nur, um Ihren Heimcomputer von unterwegs aus zu steuern.
* Zielrechner sperren: Sperrt den Zielrechner.
* Verbindungsdetails anzeigen: Bietet detaillierte Informationen zu Ihrer Verbindung sowie zum Zielrechner. Zu den Informationen gehören:
    * Verbindungsstatistiken
    * Informationen zum Computer, einschließlich Betriebssystemversion, verfügbarem Arbeitsspeicher usw.
    * Laufende Prozesse
    * Installierte Pakete
* KI-Tools: Ermöglicht es Ihnen, mit einer Reihe von Chatbots zu kommunizieren, die auf Barrierefreiheit ausgerichtet sind.
    * Diese Option steht nur Controllern zur Verfügung, die über einen Pro-Pass verfügen oder ein Abonnement für die „Personal Community“, den „Weekend Support“ oder die „Pro/Enterprise“-Tarife haben.
* Sitzung trennen (**Windows+Umschalt+D**): Beendet die Sitzung.
    * Beachten Sie, dass diese Option beiden Seiten der Sitzung zur Verfügung steht.

</Windows>

### Sitzungs-Chat

Die Textkommunikation über die in RIM integrierte Sitzungs-Chat-Funktion kann in Situationen nützlich sein, in denen ein Sprachgespräch nicht möglich oder nicht praktikabel ist. Sie kann sogar als Ergänzung zu einem bestehenden Sprachgespräch genutzt werden, z. B. zum Senden von Links, Anweisungen oder Ähnlichem.  

#### Einen Chat starten

Ein Sitzungs-Chat kann auf eine der folgenden Arten initiiert werden:  

* Auf der Controller-Seite
    * Ein Controller kann im Sitzungsmenü die Option „Chat öffnen“ auswählen.
    * Wenn das Chat-Fenster auf dem steuernden Computer erscheint, liegt der Fokus im Eingabefeld, in das eine Nachricht eingegeben und mit der Eingabetaste gesendet werden kann.
    * Eine an den Zielbenutzer gesendete Nachricht öffnet auf dessen Rechner ein Chat-Fenster. Ab diesem Zeitpunkt ist ein Chat hin und her möglich.
    * Beachten Sie, dass es nicht möglich ist, den Zielcomputer zu steuern, solange das Chat-Fenster des Benutzers im Fokus ist. Die Steuerung des Zielcomputers wird wieder aufgenommen, wenn eine der folgenden Bedingungen erfüllt ist:
        * Der Zielbenutzer verlagert den Fokus vom Chat-Fenster weg; in diesem Fall kann die Steuerung wieder aufgenommen werden, bis er den Fokus wieder auf das Chat-Fenster verlagert.
        * Der Zielbenutzer schließt das Chat-Fenster durch Drücken der Escape-Taste.
        * Wenn das Chat-Fenster auf dem steuernden Computer geschlossen ist und 30 Sekunden vergangen sind, wird das Chat-Fenster des Zielbenutzers automatisch deaktiviert; ab diesem Zeitpunkt wird die Steuerung wieder aufgenommen.
* Auf der Zielseite:
    * Der Zielbenutzer kann im Sitzungsmenü die Option „Chat öffnen“ auswählen. Dadurch wird sofort ein Chat-Fenster auf dem steuernden Computer ausgelöst.
    * Ab diesem Zeitpunkt ist ein gegenseitiger Chat möglich.
    * Wenn der Zielbenutzer das Chat-Fenster auf seiner Seite schließt, bleibt das Chat-Fenster auf dem steuernden Computer geöffnet. Eine nachfolgende Nachricht des Steuernden reaktiviert das Chat-Fenster auf dem Zielcomputer.

#### Arbeiten im Chat

Solange das Chat-Fenster im Fokus ist, werden eingehende Nachrichten sowohl sprachlich als auch in Braille dargestellt. Ein Computer, auf dem das Chat-Fenster nicht im Fokus ist, wird über Standard-Windows-Toast-Benachrichtigungen auf Chat-Nachrichten hingewiesen.  
Außerhalb des Nachrichtenfensters lässt sich der Chat wie eine normale Webseite navigieren. Nachrichten, die von der Gegenpartei gesendet wurden, können über die Schaltfläche „Kopieren“ neben der betreffenden Nachricht in die Zwischenablage kopiert werden.

#### Chat-Protokolle

Chat-Protokolle werden in einem vom Benutzer konfigurierbaren Verzeichnis gespeichert. Standardmäßig ist dies das Verzeichnis „documents/Remote Incident Manager/Chat“ in Ihrem Benutzerordner.

Derzeit kann das Verzeichnis nur über eine Konfigurationsdatei geändert werden, daher ist die Anleitung nur auf Englisch verfügbar.  

<Windows>

Der Zugriff auf die Konfigurationsdatei erfolgt über den Ausführungsdialog, indem Sie Folgendes einfügen:  
%appdata%\remote-incident-manager\config.toml  

</Windows>

<MacOS>

Die Datei „config.toml“ befindet sich unter $HOME/Library/Application Support/remote-incident-manager

</MacOS>

Suchen Sie in der Konfigurationsdatei die Zeile <settingID>directory</settingID> unterhalb der Zeile <settingID>Chat</settingID> und ändern Sie das Verzeichnis nach Belieben.  
Beachten Sie, dass Backslashes bei Windows-Verzeichnissen ordnungsgemäß maskiert werden müssen.  
Sobald Sie die Konfiguration speichern, werden die Änderungen für nachfolgende Sitzungen wirksam. Ein Neustart der Anwendung ist nicht erforderlich.

### Dateiübertragungen

RIM bietet unabhängig von der verwendeten Plattform einige einfache Möglichkeiten zur Dateiübertragung.

#### Dateiübertragungen über die Zwischenablage

1. Rufen Sie das RIM-Menü auf und klicken Sie auf „Sitzung minimieren“. Die Steuerung wird wieder auf Ihren Computer zurückgeführt.
1. Wählen Sie die Datei(en) und/oder Ordner(e), die Sie übertragen möchten, mit Ihrem Dateimanager aus.
1. Kopieren Sie den ausgewählten Inhalt wie gewohnt in die Zwischenablage. Sie erhalten eine Benachrichtigung, dass eine Datei zur Übertragung bereit ist. Sie haben zwei Möglichkeiten.
1. **Wenn das Ziel ein Mac ist:**
    * Rufen Sie das RIM-Sitzungsmenü auf und klicken Sie auf die Option „Datei an Ziel übertragen“.
    * Nach Abschluss der Übertragung erstellt der Ziel-Mac ein temporäres Verzeichnis mit den übertragenen Inhalten. Diese sollten anschließend kopiert und in die vorgesehenen Verzeichnisse eingefügt werden.
1. **Wenn das Ziel ein Windows-Rechner ist:**
    * Wechseln Sie zurück zur Remote-Sitzung und suchen Sie auf dem Zielrechner den Ordner, in den Sie den Inhalt einfügen möchten.
    * Zu guter Letzt fügen Sie den Inhalt wie gewohnt ein.

Beachten Sie, dass die Übertragungsdauer vollständig von der Größe der zu sendenden Inhalte sowie von Ihrer Netzwerkgeschwindigkeit abhängt.

#### Der Dateibrowser

Mithilfe des Dateibrowsers können Sie als Controller Dateien über eine einheitliche Oberfläche nahtlos zum und vom Zielcomputer übertragen. Dies ist besonders praktisch, wenn Sie Endbenutzern häufig Unterstützung leisten, die eine andere Desktop-Plattform als Sie selbst verwenden. Darüber hinaus ermöglicht der Dateibrowser die Übertragung von Dateien, ohne dass der Endbenutzer von der Aufgabe, an der er gerade arbeitet, abgelenkt wird.  
Neben der Dateiübertragung können über die integrierte Dateibrowser-Oberfläche Dateien und Ordner umbenannt und in den Papierkorb verschoben werden.

##### Aktivieren des Dateibrowsers

Aktivieren Sie den Dateibrowser, indem Sie im Sitzungsmenü die Option „Dateien auf dem Zielcomputer durchsuchen“ auswählen.

Hinweis: Während einer Keyword-Sitzung erfordert diese Dateiübertragungsmethode die Zustimmung des Endnutzers, um gestartet zu werden. Dies liegt daran, dass diese Funktion Dateioperationen durchführt, ohne ein Explorer- oder Finder-Fenster auf dem Zielcomputer zu öffnen.

Dem Zielbenutzer wird ein Dialogfeld angezeigt, in dem er gefragt wird, ob er die Anfrage zulassen oder ablehnen möchte. Wenn der Zielbenutzer Ihre Anfrage zum Starten der Dateiübertragung akzeptiert, gelangen Sie in ein Dateibrowser-Fenster. Wenn Sie die Anfrage abbrechen oder der Zielbenutzer sie ablehnt, kehren Sie zur Remote-Sitzung zurück.

##### Verwendung des Dateibrowsers

Das Dateibrowser-Fenster verfügt über ein Layout mit zwei Listen, ähnlich wie man es von multifunktionalen Dateimanagern wie Total Commander oder FTP-Clients wie FileZilla kennt. Der Fokus liegt zunächst auf der Verzeichnisstruktur Ihres eigenen Systems, die sich auf der linken Seite des Bildschirms befindet. Die Verzeichnisauflistung des Zielcomputers wird auf der rechten Seite des Bildschirms angezeigt und lässt sich bequem über die Tabulatortaste aufrufen.

<Windows>

1. Wählen Sie ein Element (oder mehrere Elemente) in einer der beiden Listen aus. Mit den folgenden Tasten können Sie durch die Verzeichnisse navigieren:
    * Eingabetaste: Öffnet einen Ordner.
    * Rücktaste: Wechselt eine Ebene höher, d. h. zurück in den übergeordneten Ordner.
2. Wenn Sie mit der Auswahl zufrieden sind, drücken Sie Strg+C, um die Elemente zu kopieren.
3. Wechseln Sie zur anderen Liste und drücken Sie Strg+V, um die Elemente einzufügen. Beachten Sie, dass die Übertragungszeit vollständig von der Größe der zu sendenden Inhalte sowie von Ihrer Netzwerkgeschwindigkeit abhängt.
4. In beiden Listen haben Sie folgende Möglichkeiten:
    * Drücken Sie F2, um ein Element umzubenennen.
    * Drücken Sie die Entf-Taste, um die ausgewählten Elemente in den Papierkorb zu verschieben.
        * RIM löscht unter keinen Umständen eine Datei endgültig.
    * Drücken Sie F5, um eine Liste zu aktualisieren.

</Windows>

<MacOS>

1. Wählen Sie ein Element (oder mehrere Elemente) in einer der beiden Listen aus. Mit den folgenden Tasten können Sie durch die Verzeichnisse navigieren:
    * Return: Öffnet einen Ordner.
    * Entf oder Befehlstaste+Pfeil nach oben: Wechselt eine Ebene höher, d. h. zurück in den übergeordneten Ordner.
2. Wenn Sie mit der Auswahl zufrieden sind, drücken Sie „Befehlstaste+C“, um die Elemente zu kopieren.
3. Wechseln Sie zur anderen Liste und drücken Sie „Befehlstaste+V“, um die Elemente einzufügen. Beachten Sie, dass die Übertragungszeit vollständig von der Größe der zu sendenden Inhalte sowie von Ihrer Netzwerkgeschwindigkeit abhängt.
4. In beiden Listen haben Sie folgende Möglichkeiten:
    * Drücken Sie F2, um ein Element umzubenennen.
    * Drücken Sie Befehlstaste+Löschtaste, um die ausgewählten Elemente in den Papierkorb zu verschieben.
        * RIM löscht unter keinen Umständen eine Datei endgültig.
    * Drücken Sie Befehlstaste+R, um eine Liste zu aktualisieren.

</MacOS>

##### Bekannte Einschränkungen

###### Wiederherstellung nach Stromausfall

* Wenn RIM während eines Uploads aufgrund eines Absturzes oder eines Stromausfalls unterbrochen wird, verbleiben unvollständige Dateien auf dem Zielgerät. Nur eine absichtliche Abbruchaktion oder ein dokumentierter Übertragungsfehler entfernt diese unvollständigen Dateien.

###### Dateilöschung bei Wechseldatenträgern

Einige Wechseldatenträger verfügen über keinen internen Papierkorb. Wenn Sie versuchen, eine Datei von einem dieser Datenträger zu löschen, weist RIM Sie deutlich auf diese Einschränkung hin und bricht den Löschvorgang ab. Diese Sicherheitsmaßnahme stellt sicher, dass RIM niemals versehentlich einen endgültigen Löschvorgang durchführt.

Wenn Sie einem Endbenutzer beim Löschen einer Datei helfen und auf diese Einschränkung stoßen, können Sie auf dem Zielcomputer zur Datei navigieren und sie auf die übliche Weise löschen. Wenn Sie eine Datei auf diese Weise löschen, übernimmt das Betriebssystem den Datei-Vorgang, nicht RIM.

###### Einschränkungen unter macOS

* Mac-Apps und -Pakete, d. h. Dateien mit der Endung .app oder .pkg, können nicht kopiert werden. RIM fordert Sie auf, diese in eine ZIP-Datei zu komprimieren – ein Vorgang, der außerhalb des Dateibrowsers durchgeführt werden muss.
* Auf Inhalte aus iCloud Drive kann über den Dateibrowser nicht zugegriffen werden.
* Ein Upload auf einen Mac wird abgelehnt, wenn ein Pfad 1024 Byte oder länger ist.

###### Dateiattribute und Berechtigungen

* Die Attribute „Schreibgeschützt“ und „Versteckt“ werden nicht kopiert.
* Das Ausführungsbit bleibt nur bei Dateien erhalten, die auf einen Mac kopiert werden. Heruntergeladene Dateien sind aus Sicherheitsgründen niemals ausführbar.

### Sitzungsaufzeichnung

Die Sitzungsaufzeichnungsfunktion von RIM ermöglicht es Ihnen als Sitzungsleiter, den Inhalt Ihrer Sitzung bequem in einer Datei auf Ihrem Computer aufzuzeichnen. Diese Datei kann anschließend an die Person weitergeleitet werden, der Sie Fernunterstützung leisten. Der Inhalt der Sitzungsaufzeichnung umfasst die audiovisuelle Ausgabe des Zielcomputers sowie den Ton eines laufenden Sprachgesprächs.
So führen Sie eine Sitzungsaufzeichnung durch:  

<Windows>

        * Wenn der Zielbenutzer zustimmt, beginnt die Aufzeichnung. Wenn der Zielbenutzer die Aufzeichnung ablehnt, wird die gesamte Sitzung beendet.
    * Bei aufgeforderten/unbeaufsichtigten Sitzungen:
        * Die Aufzeichnung beginnt sofort.
    * Unabhängig davon erhalten beide Parteien eine Benachrichtigung, dass die Aufzeichnung begonnen hat, sobald diese tatsächlich startet.
1. Um die Aufzeichnung anzuhalten oder fortzusetzen, rufen Sie die Umschaltfläche „Sitzungsaufzeichnung anhalten/fortsetzen“ im Sitzungsmenü auf.
    * Die Aufzeichnung wird entsprechend angehalten oder fortgesetzt.
    * Beide Parteien erhalten eine entsprechende Benachrichtigung.
1. Die Aufzeichnung kann über die Option „Sitzungsaufzeichnung beenden“ im Sitzungsmenü gestoppt werden.
    * Standardmäßig erscheint ein Bestätigungsdialog, in dem Sie gefragt werden, ob Sie die Aufzeichnung beenden möchten. Dieser Dialog soll ein versehentliches Beenden der Sitzungsaufzeichnung verhindern, kann jedoch optional deaktiviert werden.

    * Die Aufzeichnung wird dann in dem Verzeichnis gespeichert, in dem RIM Ihre Aufzeichnungen standardmäßig speichert (standardmäßig ist dies der Ordner „Videos“ in Ihrem Benutzerverzeichnis). Der Einfachheit halber werden Sie automatisch über den Explorer in diesen Ordner weitergeleitet, sodass Sie die Aufzeichnung bei Bedarf an den Benutzer senden können.

</Windows>

        * Die Aufzeichnung beginnt sofort.

1. Um die Aufzeichnung anzuhalten oder fortzusetzen, rufen Sie die Umschaltfläche „Sitzungsaufzeichnung anhalten/fortsetzen“ im Sitzungsmenü auf.

Aufzeichnungen sind eine völlig kostenlose Funktion, die jedem Benutzer in jeder Tarifstufe zur Verfügung steht. Darüber hinaus werden Aufzeichnungen vollständig lokal verarbeitet, ohne dass der Cloud-Dienst daran beteiligt ist.

#### Hinweis zum Fernzugriffsmodul

Da das Fernzugriffsmodul seine Sprachausgabe an Ihre laufende NVDA-Instanz weiterleitet, muss RIM dies berücksichtigen, um diese Sprachausgabe in einer Aufzeichnung zu erfassen. Daher initiiert RIM immer dann, wenn der Fernzugriff während einer Aufzeichnung aktiv ist, eine Erfassung der gesamten Audioausgabe Ihres Systems. Dadurch kann die über das Fernzugriffsmodul hörbare Sprachausgabe genau so erfasst werden, wie sie während der Sitzung zu hören war. Dies kann zwar dazu führen, dass einige Benachrichtigungstöne Ihres steuernden Computers in der Aufzeichnung mit aufgenommen werden, führt jedoch nicht dazu, dass Audio vom Zielcomputer doppelt wiedergegeben wird.

#### Hinweis für den Einsatz in Unternehmen

Um den typischen Sicherheitsanforderungen in Unternehmen gerecht zu werden, ist die Sitzungsaufzeichnung in Unternehmensumgebungen eine Funktion, die ausschließlich nach ausdrücklicher Zustimmung (Opt-in) genutzt werden kann. Sofern die Aufzeichnungsfunktion nicht von einem Organisationsadministrator aktiviert wurde, stehen den RIM-Controllern innerhalb der Organisation daher keine Mechanismen zur Aufzeichnung zur Verfügung.

#### Erweiterte Konfiguration für Sitzungsaufzeichnungen

RIM bietet eine Reihe erweiterter Konfigurationsoptionen für die Sitzungsaufzeichnung. Dazu gehören die Möglichkeit, Aufzeichnungen beim Start der Sitzung automatisch zu starten, Aufzeichnungen in einem alternativen Pfad (z. B. einer Netzwerkfreigabe) zu speichern und den Status des Bestätigungsdialogs beim Beenden einer Aufzeichnung festzulegen. Derzeit können diese Einstellungen ausschließlich über eine Konfigurationsdatei geändert werden, weshalb die Anleitung nur auf Englisch verfügbar ist.  

<Windows>

Der Zugriff auf die Konfigurationsdatei erfolgt über den Ausführen-Dialog, indem Sie Folgendes einfügen:  
%appdata%\remote-incident-manager\config.toml  

</Windows>

<MacOS>

Die Datei „config.toml“ befindet sich unter $HOME/Library/Application Support/remote-incident-manager

</MacOS>

In der Konfigurationsdatei stehen Ihnen die folgenden Optionen zur Verfügung:

* <settingID>directory</settingID>: Legt das Verzeichnis zum Speichern von Aufzeichnungen fest.
    * Bei Windows-Verzeichnissen müssen Backslashes ordnungsgemäß maskiert werden.  
* <settingID>auto_start</settingID>: Legt fest, ob die Sitzungsaufzeichnung sofort nach Beginn der Sitzung startet. Diese Option ist standardmäßig auf <settingID>false</settingID> gesetzt.  
* <settingID>suppress_stop_confirmation</settingID>: Legt fest, ob beim manuellen Beenden einer Aufzeichnung ein Bestätigungsdialog angezeigt wird. Der Standardwert ist <settingID>false</settingID>.
    * Beachten Sie, dass das Trennen einer Sitzung die Aufzeichnung unabhängig von dieser Einstellung immer ohne Bestätigung beendet.

Sobald Sie die Konfiguration speichern, werden die Änderungen für nachfolgende Sitzungen wirksam. Ein Neustart der Anwendung ist nicht erforderlich.

### Modul für Fernzugriff und Barrierefreiheit

Ganz gleich, ob Sie einem Benutzer helfen, der keinen Bildschirmleser verwendet, oder ob Sie ein Problem mit einem fehlerhaften Bildschirmleser diagnostizieren – RIM steht Ihnen jederzeit zur Seite.

<Windows>

Das Fernzugriffsmodul für Barrierefreiheit besteht aus zwei Komponenten:
* Ein Add-on für den NVDA-Bildschirmleser, das es dem Bildschirmleser ermöglicht, Ausgaben vom Remote-Computer zu empfangen
* Ein eigenständiges Barrierefreiheitsmodul, das auf Anfrage des Controllers auf dem Zielcomputer gestartet wird. Der Vorteil dieses Ansatzes besteht darin, dass der Endnutzer keine Sprachausgabe auf seinem Computer hört, während Sie diesen steuern. Stattdessen leitet das Fernzugriffsmodul die Sprachausgabe an die auf der Controller-Seite laufende Instanz von NVDA weiter. Auf diese Weise können Sie einem Endnutzer barrierefrei helfen, ohne dass dieser einen Screenreader installieren oder gar herunterladen muss.

### Einrichtungsvorgang

Für die erstmalige Initialisierung des Barrierefreiheitsmoduls müssen Sie Folgendes tun:

1. Stellen Sie eine Verbindung zu einem Computer her, auf dem kein Bildschirmleseprogramm läuft.
1. Falls NVDA gerade läuft, werden Sie aufgefordert, ein Add-on zu installieren, das es Ihrer NVDA-Instanz ermöglicht, während der Sitzung mit dem Remote-Computer zu kommunizieren. Bestätigen Sie die Installationsaufforderungen und warten Sie, bis NVDA neu gestartet ist.
1. Nun ist das Remote-Barrierefreiheitsmodul vollständig initialisiert, und Sie hören Sprachausgabe, während Sie den Remote-Computer steuern. Um die Sprachausgabe vorübergehend stummzuschalten, drücken Sie einfach einmal die Einfg-Taste oder die Tastenkombination Feststelltaste+S; um sie wieder zu aktivieren, drücken Sie diesen Befehl zweimal.

Wenn Sie ab diesem Zeitpunkt einen Screenreader auf dem steuernden Computer ausführen, startet das Remote-Barrierefreiheitsmodul automatisch während Fernsitzungen, in denen auf dem Remote-Computer kein Screenreader läuft. Sollten Sie einen anderen Screenreader als NVDA verwenden, deaktiviert RIM diesen Screenreader und schaltet Sie dann auf NVDA um. Wenn Sie das Remote-Barrierefreiheitsmodul auf dem Remote-Rechner anhalten müssen, um einen anderen Screenreader zu starten, wählen Sie einfach die Option „Remote-Barrierefreiheit anhalten“ aus dem RIM-Menü.  

</Windows>

<MacOS>

Das Remote-Barrierefreiheitsmodul ist eine spezielle Konfiguration, die auf dem Ziel-Mac auf Anfrage eines Windows- oder Mac-Steuercomputers initiiert wird. Der Vorteil dieses Ansatzes besteht darin, dass der Endbenutzer auf seinem Computer keine Sprachausgabe hört, während Sie ihn steuern. Stattdessen leitet das Remote-Barrierefreiheitsmodul die Sprachausgabe an das Sprachsystem auf der Seite des Steuercomputers weiter. Auf diese Weise können Sie einem Endbenutzer barrierefrei helfen, ohne dass dieser einen Screenreader aktivieren muss. Wenn Sie auf dem steuernden Mac VoiceOver ausführen, wird das Remote-Accessibility-Modul automatisch während Fernsitzungen gestartet, in denen auf dem Remote-Computer kein Screenreader läuft.  

</MacOS>

## Neustart und erneute Verbindung

Ganz gleich, ob Sie Systemaktualisierungen installieren oder einen Systemabsturz beheben – das RIM unterstützt Sie während des Neustartvorgangs. Wenn Sie im RIM-Menü die Option „Neustart und erneute Verbindung“ auswählen, können Sie je nach Zustand des Computers entweder einen ordentlichen Neustart oder einen Notneustart durchführen. Während der Neustart des Computers läuft, informiert Sie RIM darüber, dass Versuche zur Wiederherstellung der Verbindung unternommen werden.

Beachten Sie: Wenn der Computer durch eine Softwareinstallation neu gestartet oder auf herkömmliche Weise manuell neu gestartet wird, werden Sie gefragt, ob Sie die Sitzung wiederherstellen möchten. Zu beachten ist außerdem, dass Mac-Zielgeräte in beiden Fällen erst dann wieder verbunden werden, wenn sich der Benutzer angemeldet hat. Dies liegt daran, dass RIM aufgrund von Plattformbeschränkungen – insbesondere der FileVault-Festplattenverschlüsselung – nicht automatisch auf dem Anmeldebildschirm gestartet werden kann.

### Unbeaufsichtigter oder abgefragter Zugriff

RIM ermöglicht es Ihnen als Controller, Computer für den unbeaufsichtigten oder abgefragten Zugriff zu konfigurieren. Auf diese Weise können Sie Fernunterstützung leisten, ohne dass der Benutzer RIM starten, ein Schlüsselwort eingeben oder sich gar in der Nähe des Computers befinden muss. Dies ist nützlich, wenn Sie als Systemadministrator routinemäßige Wartungsarbeiten an Computern in Ihrer Arbeitsgruppe durchführen oder wenn Sie regelmäßig Support für Kunden leisten. Möglicherweise möchten Sie auch den unbeaufsichtigten Zugriff für Ihren Heimcomputer zulassen, falls Sie von einem anderen Ort aus darauf zugreifen müssen.

Es gibt verschiedene Möglichkeiten, Computer für den unbeaufsichtigten Zugriff zu konfigurieren.

#### Während einer interaktiven Sitzung

1. Rufen Sie das RIM-Menü auf.
1. Wählen Sie „Unbeaufsichtigten oder abgefragten Zugriff anfordern“.
1. Sie werden gefragt, welche Art von Verbindung Sie konfigurieren möchten. Ihre Optionen sind:
    1. Unbeaufsichtigt: Ermöglicht das Starten von Sitzungen ohne jegliches Eingreifen des Endbenutzers.
    1. Mit Abfrage: Bei dieser Konfiguration erhält der Benutzer eine Meldung, die ihn darüber informiert, dass Sie eine Verbindung zu seinem Rechner herstellen. Er muss unter macOS die Tastenkombination Option+Umschalt+Y oder unter Windows die Tastenkombination Windows+Umschalt+Y drücken, wenn er die Verbindung akzeptieren möchte.
1. Sie werden aufgefordert, diesem Rechner einen Namen zu geben. Geben Sie einen eigenen Namen für den Rechner ein oder, falls zutreffend, die Rechner-ID, wie sie in Ihrer Arbeitsgruppe angezeigt wird.
1. Wenn Sie Teil einer Organisation sind oder Ihr Konto anderweitig über Zielgruppenfunktionen verfügt, werden Sie aufgefordert, diesen Rechner einer Zielgruppe zuzuweisen.
    * Wenn Sie die Standard-Zielgruppe auswählen, zeigt RIM vor dem Start der Anfrage ein zusätzliches Bestätigungsfenster an.
1. Aktivieren Sie „Anfrage senden“.
1. Auf dem Client-Rechner erscheint ein Dialogfeld, in dem der Benutzer gefragt wird, ob er damit einverstanden ist, dass sein Computer für den von Ihnen angeforderten Zugriff eingerichtet wird. Wenn er mit „Ja“ antwortet, erhalten Sie eine Meldung, dass der Zugriff genehmigt wurde.  

##### Hinweis für Inhaber eines persönlichen unbeaufsichtigten Kontos

Wenn Sie alle Ihrem Konto zugewiesenen Geräteplätze bereits belegt haben, führt RIM die Anfrage nicht aus. In diesem Fall haben Sie zwei Möglichkeiten, die beide über das RIM-Dashboard verfügbar sind:

1. Melden Sie einen Ihrer Rechner ab, um einen Platz freizugeben.
1. Erweitern Sie Ihr Abonnement um weitere Plätze.

#### Einen Rechner bei Ihrem RIM-Konto registrieren

Sollten Sie einen Ihrer eigenen Rechner für den unbeaufsichtigten Zugriff registrieren wollen, können Sie dies tun, ohne eine interaktive Sitzung mit dem Rechner starten zu müssen. 

1. Starten Sie RIM im „Receive Help“-Modus.
1. Klicken Sie auf die Schaltfläche „Diesen Rechner zu Ihrem RIM-Konto hinzufügen“.
1. Geben Sie Ihre E-Mail-Adresse ein und klicken Sie dann auf „Weiter“.
1. Warten Sie, bis Sie den Zwei-Faktor-Anmeldecode erhalten haben, geben Sie ihn ein, und Sie sollten nun angemeldet sein.
1. Sie werden gefragt, welche Art von Zugriff Sie für diesen Rechner konfigurieren möchten. Sie haben folgende Optionen:
    1. Unbeaufsichtigt: Ermöglicht das Starten von Sitzungen ohne jegliches Eingreifen des Endbenutzers.
    1. Mit Abfrage: Bei dieser Konfiguration erhält der Benutzer eine Meldung, die ihn darüber informiert, dass Sie eine Verbindung zu seinem Rechner herstellen.
1. Geben Sie dem Rechner einen Namen.
1. Wenn Sie Teil einer Organisation sind oder Ihr Konto anderweitig über Zielgruppenfunktionen verfügt, werden Sie aufgefordert, diesen Rechner einer Zielgruppe zuzuweisen.
    * Wenn Sie die Standard-Zielgruppe auswählen, zeigt RIM vor dem Auslösen der Anfrage ein zusätzliches Bestätigungsfenster an.
1. Klicken Sie auf die Schaltfläche „Rechner hinzufügen“.
1. Der Rechner wird Ihrem Konto zugeordnet, sodass sich alle als Controller fungierenden Rechner, die bei Ihrem RIM-Konto angemeldet sind, mit diesem Rechner verbinden können.

##### Hinweis für Inhaber eines persönlichen Unattended-Kontos

Wenn Sie alle Ihrem Konto zugewiesenen Rechnerplätze bereits belegt haben, führt RIM die Anfrage nicht aus. In diesem Fall haben Sie zwei Möglichkeiten, die beide über das RIM-Dashboard verfügbar sind:

1. Melden Sie einen Ihrer Rechner ab, um einen Platz freizugeben.
1. Erweitern Sie Ihr Abonnement um weitere Plätze.

#### Verbindung herstellen

Nachdem wir den Rechner nun für den unbeaufsichtigten Zugriff registriert haben, erfahren Sie hier, wie Sie eine Sitzung starten.

1. Starten Sie RIM im Controller-Modus.
1. Anstatt ein Stichwort einzugeben, suchen Sie die Registerkarte „Meine Rechner“ und aktivieren Sie sie.
1. Wenn Sie diese Registerkarte aktivieren, wird eine Liste der Geräte angezeigt. Wählen Sie das gewünschte Gerät aus und drücken Sie die Eingabetaste. Sie können auch die Suchleiste verwenden, um die Liste auf ein bestimmtes Gerät einzugrenzen.

Wenn das Zielgerät für den Zugriff mit Abfrage konfiguriert ist, erhält der Endbenutzer eine Abfrage. Sobald er mit „Ja“ antwortet, werden Sie verbunden. Handelt es sich um eine unbeaufsichtigte Sitzung, werden Sie sofort verbunden und gelangen in den Fernsteuerungsbereich.

Bitte beachten Sie: Bei vollständig unbeaufsichtigten Sitzungen muss der Zielbenutzer Sprachgespräche genehmigen. Bei Sitzungen mit Abfrage ist dies jedoch nicht erforderlich.

#### Erstellen einer Verknüpfung für eine unbeaufsichtigte Sitzung

Für zusätzlichen Komfort können Sie Desktop-Verknüpfungen erstellen, mit denen Sie unbeaufsichtigte Sitzungen automatisch starten können. Gehen Sie dazu wie folgt vor:

1. Rufen Sie die Liste der unbeaufsichtigten Computer auf der Registerkarte „Meine Rechner“ auf und wählen Sie den Rechner aus, für den Sie eine Verknüpfung erstellen möchten.
1. Klicken Sie auf die Schaltfläche „Verknüpfung erstellen“.
1. Eine Verknüpfung wird automatisch auf Ihrem Desktop hinzugefügt.

Wenn Sie diese Verknüpfung nun aktivieren, gelangen Sie entweder automatisch in die Remote-Sitzung oder es wird eine Aufforderung an den Computer des Benutzers gesendet, die dieser akzeptieren kann.

<Windows>

##### Weitere Verwendungsmöglichkeiten für Verknüpfungen zu unbeaufsichtigten Sitzungen

Verknüpfungen zu unbeaufsichtigten Sitzungen können, wie alle anderen Verknüpfungen auch, mit globalen Tastenkombinationen belegt werden. Dies kann äußerst nützlich sein, wenn Sie als Wartungstechniker mehrere Computer in einer Arbeitsgruppe verwalten. Wenn Ihre Arbeitsgruppe beispielsweise aus 6 Computern besteht, an denen Sie routinemäßige Wartungsarbeiten durchführen, könnten Sie die Tastenkombinationen Alt+Strg+1 bis 6 als Tastenbefehle für die jeweiligen Rechner konfigurieren. Dies dürfte Ihren Arbeitsablauf erheblich beschleunigen.
Darüber hinaus können Sie eine unbeaufsichtigte Sitzung über das Feld „Ausführen“ aufrufen, wenn Sie die Verknüpfung in Ihr Benutzerverzeichnis kopieren. Sobald Sie die Verknüpfung kopiert haben, können Sie eine unbeaufsichtigte Sitzung starten, indem Sie „Ihr-Sitzungsname.url“ in das Feld „Ausführen“ eingeben.

</Windows>

#### Unbeaufsichtigten Zugriff widerrufen

Wenn Sie nicht mehr möchten, dass Ihr Rechner unbeaufsichtigt gesteuert wird, können Sie den Zugriff des Controllers widerrufen. Dazu müssen Sie sich nicht in einer Sitzung befinden.

<Windows>

1. Rufen Sie das Symbol „Remote Incident Manager“ in Ihrer Taskleiste auf.
    1. Wenn Sie die Tastatur verwenden, drücken Sie Windows+B, dann die Leertaste und anschließend die Pfeiltaste nach links oder rechts, bis Sie das Symbol gefunden haben.
1. Klicken Sie mit der rechten Maustaste auf dieses Symbol oder drücken Sie die Anwendungstaste bzw. Umschalt+F10.
1. Wählen Sie die Option „Unbeaufsichtigten Zugriff widerrufen“ aus.
1. Es wird eine Liste mit Computern angezeigt; wählen Sie den Computer aus, für den Sie den Zugriff widerrufen möchten.
1. Sie werden gefragt, ob Sie den Zugriff für den Computer widerrufen möchten; antworten Sie mit „Ja“.  

</Windows>

<MacOS>

1. Rufen Sie das Symbol „Remote Incident Manager“ in Ihren Menü-Extras bzw. Statusmenüs auf.
    1. Wenn Sie VoiceOver verwenden, drücken Sie zweimal „VO+M“ und suchen Sie anschließend das Menüsymbol „Remote Incident Manager“.
    1. Klicken Sie auf dieses Symbol oder drücken Sie VO+Leertaste.  
1. Wählen Sie die Option „Unbeaufsichtigten Zugriff widerrufen“ aus.
1. Es wird eine Liste mit Computern angezeigt; wählen Sie den Computer aus, für den Sie den unbeaufsichtigten Zugriff widerrufen möchten.
1. Sie werden gefragt, ob Sie den unbeaufsichtigten Zugriff für diesen Computer widerrufen möchten; antworten Sie mit „Ja“.  

</MacOS>

Das war’s schon! Der Controller erhält eine Meldung, dass dieser Computer nicht mehr für den unbeaufsichtigten Zugriff verfügbar ist. Sollte der unbeaufsichtigte Zugriff erneut benötigt werden, kann der Benutzer den Vorgang wie oben beschrieben erneut starten, um die Berechtigung für den unbeaufsichtigten Zugriff anzufordern.
